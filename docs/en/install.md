# Install & Upgrade

[简体中文](../zh/install.md) | [English](../en/install.md)

NodeRS runs on Linux only. The install scripts detect `x86_64` / `aarch64` and `glibc` (2.36+) / `musl`, then pick the matching release bundle automatically. Use `install.sh` on systemd systems and `install-openrc.sh` on OpenRC-only distributions (such as Alpine).

## System Requirements

| Item | Requirement |
| --- | --- |
| OS | Linux (systemd or OpenRC) |
| Architecture | `x86_64` / `aarch64` |
| libc | glibc 2.36+ or musl |
| Network | The node must reach the panel API; the panel must reach the node's listen ports |

## One-command Install

```bash
curl -fsSL https://raw.githubusercontent.com/MoeclubM/NodeRS/main/scripts/install.sh | bash -s -- \
  --api https://api.example.com \
  --key MACHINE_KEY \
  --machine-id 1
```

OpenRC:

```bash
curl -fsSL https://raw.githubusercontent.com/MoeclubM/NodeRS/main/scripts/install-openrc.sh | bash -s -- \
  --api https://api.example.com \
  --key MACHINE_KEY \
  --machine-id 1
```

To connect one server to multiple panels, repeat `--machine <url> <key> <id>`; different APIs may share the same `machine_id` because instance names are derived from an `api + machine_id` hash:

```bash
curl -fsSL https://raw.githubusercontent.com/MoeclubM/NodeRS/main/scripts/install.sh | bash -s -- \
  --machine https://secapi.example.com KEY_A 10 \
  --machine https://api.example.com KEY_B 10
```

## Installer Options

| Option | Description |
| --- | --- |
| `--version <tag>` | Release tag to install, default `latest` |
| `--prefix <path>` | Binary installation prefix, default `/usr/local` |
| `--config-dir <path>` | Config directory, default `/etc/noders/anytls` |
| `--state-dir <path>` | Working directory, default `/var/lib/noders/anytls` |
| `--api <url>` | Xboard API address |
| `--key <token>` | Xboard machine key |
| `--machine-id <id>` | Xboard machine ID; with `--uninstall`, removes all local instances for that ID |
| `--machine <url> <key> <id>` | Add one machine triplet, may be repeated; with `--uninstall`, removes exactly that instance |
| `--uninstall` | Remove installed services, binaries, and related files |
| `--all` | With `--uninstall`, remove all nodes and all data |
| `--no-service` | Install files only, skip service registration |
| `-h, --help` | Show help |

When run from the repo or a raw URL the script downloads the release bundle automatically; when run inside an already-unpacked release bundle it installs from local files without downloading.

## Local Config File

Each instance has a local TOML config at `/etc/noders/anytls/machines/<machine_id>-<api_hash>.toml`, generated by the installer, containing only the panel connection info (`config.example.toml`):

```toml
[panel]
api = "https://xboard.example.com"
key = "replace-me"
machine_id = 1
```

`key` must be that machine's machine key. Nodes, users, listen address, port, and TLS are all provisioned from the panel (`url` / `token` are accepted as aliases for `api` / `key`). After editing this file by hand, run `noders restart`.

The daemon is started as `noders <config path>` (falling back to `config.toml` in the working directory); the installed service already passes the right path, so you rarely need to run it manually.

## Building from Source

Requires Rust (edition 2024, latest stable recommended):

```bash
git clone https://github.com/MoeclubM/NodeRS.git
cd NodeRS
cargo build --release
```

The binary lands at `target/release/noders`. `scripts/verify-pure-rust.sh` checks dependency purity and `scripts/package-release-bundle.sh` assembles the release bundle layout.

## Upgrade

Upgrade to the latest release with the management command:

```bash
noders update
# pin a version / skip restarting afterwards
noders update --version v0.1.36
noders update --no-restart
```

Or with the script (machine configs, certificates, ACME accounts, and state are preserved; legacy `noders-anytls` binaries and `noders-<machine_id>` names are migrated to the current instance names before the binary is swapped):

```bash
curl -fsSL https://raw.githubusercontent.com/MoeclubM/NodeRS/main/scripts/upgrade.sh | bash -s --
```

## Uninstall

Remove every local instance of one machine by `machine_id`:

```bash
curl -fsSL https://raw.githubusercontent.com/MoeclubM/NodeRS/main/scripts/install.sh | bash -s -- \
  --uninstall \
  --machine-id 1
```

When several APIs share the same `machine_id`, pass the original `--machine <url> <key> <id>` to remove just that one instance:

```bash
curl -fsSL https://raw.githubusercontent.com/MoeclubM/NodeRS/main/scripts/install.sh | bash -s -- \
  --uninstall \
  --machine https://api.example.com MACHINE_KEY 1
```

Wipe NodeRS from this host:

```bash
curl -fsSL https://raw.githubusercontent.com/MoeclubM/NodeRS/main/scripts/install.sh | bash -s -- \
  --uninstall \
  --all
```

## Panel Sync Endpoints

| API | Purpose |
| --- | --- |
| `/api/v2/server/machine/nodes` | Node membership |
| `/api/v2/server/config` | Node settings |
| `/api/v2/server/user` | Users |
| `/api/v2/server/report` | Traffic and alive IPs |
| `/api/v2/server/machine/status` | Host status |
| `/api/v2/server/handshake` | WebSocket; falls back to HTTP polling when empty |

Protocols are served by Aerion: AnyTLS, Hysteria2, Mieru, Naive, Shadowsocks, Trojan, TUIC, VLESS, VMess. Wire-level limits are documented in the [Aerion docs](https://github.com/MoeclubM/Aerion/blob/main/docs/limitations.md).
